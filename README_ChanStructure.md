# ChanStructure：四种色块的可审计近似版

运行：`streamlit run ChanStructure_Streamlit.py`

`ChanStructure_Streamlit.py` 与 `chan_addons.py` 必须放在同一文件夹；后者提供两个副图和 Quote List 扫描功能。

色块不是对截图中原指标的逆向复制，而是公开规则的呈现：

- 亮绿：向上、达到“大中枢最少延伸笔数”（默认 9 笔）的中枢；
- 绿：向上、未达到该笔数的中枢；
- 紫：向下、未达到该笔数的中枢；
- 红：向下、达到该笔数的中枢。

中枢由连续三笔价格范围的交集 `[ZD, ZG]` 得到。每一笔继续与此区间重叠便为延伸；图中 `7笔`、`9笔` 是实际延伸笔数，并非交易评级。

当前版本会先处理 K 线包含关系，再识别严格顶底分型并构造笔。黄虚线是由连续高低点推进关系构成的**简化线段**；它不覆盖所有特征序列和线段破坏的流派差异，因此不应视为严格线段的最终实现。

`1买/卖` 使用“价格创新高低且 MACD 柱体面积变弱”的背驰候选规则；`2买/卖` 使用一买卖后的不破前低/不创新高回试；`3买/卖` 使用离开中枢后的首次中枢外回试。这些标记均是候选，仍需低级别确认、流动性检查和风险管理。

## 新增副图与扫描

- **海底捞月（四级近似）**：来自 RSI 与随机指标的 `Tide`/`Signal` 组合；依次显示小底、中底、大底、超大底。层级越高，要求的超卖深度、回看新低长度和成交量条件越严格。公开的“海底捞月”名称没有一套可核验的统一公式，因此它不是某个商业指标的宣称复刻。
- **CD+RSI Buy/Sell**：移植自本机的 `LZK_CD_RSI_Confirmed` Thinkorswim 源码，保留 CD/MACD 背离状态机与 RSI 背离确认。它是第二个副图，而不是“主力资金流”或机构持仓数据。
- **LZK-Quote 扫描**：侧栏按钮读取 `C:\Users\luzhe\Downloads\缠论AI\LZK-Quote.csv` 的代码清单，使用当前选择的周期与参数寻找“近期主图 1/2/3 买”且“海底捞月或 CD+RSI 抄底”的代码。默认查看最近 3 根 K 线，可调整。444 个代码的全量扫描会受 Yahoo Finance 限流、代码可用性和网络速度影响。

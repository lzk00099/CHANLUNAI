# ChanStructure：四种色块的可审计近似版

运行：`streamlit run ChanStructure_Streamlit.py`

色块不是对截图中原指标的逆向复制，而是公开规则的呈现：

- 亮绿：向上、达到“大中枢最少延伸笔数”（默认 9 笔）的中枢；
- 绿：向上、未达到该笔数的中枢；
- 紫：向下、未达到该笔数的中枢；
- 红：向下、达到该笔数的中枢。

中枢由连续三笔价格范围的交集 `[ZD, ZG]` 得到。每一笔继续与此区间重叠便为延伸；图中 `7笔`、`9笔` 是实际延伸笔数，并非交易评级。

`1买/卖` 使用“价格创新高低且 MACD 柱体面积变弱”的背驰候选规则；`2买/卖` 使用一买卖后的不破前低/不创新高回试；`3买/卖` 使用离开中枢后的首次中枢外回试。这些标记均是候选，仍需低级别确认、流动性检查和风险管理。
